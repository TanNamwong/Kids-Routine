# 🎒 Kids Routine

เว็บแอป (PWA) เตรียมชุด / ของ / เช็คลิสต์ก่อนไปโรงเรียน + สะสมดาวเด็กดี ใช้ได้ทั้ง Android และ iPhone

## วิธีลง GitHub (ไม่มีโฟลเดอร์ ไฟล์เรียงแบนทั้งหมด)
1. สร้าง repository ใหม่ (Public)
2. กด **Add file → Upload files** แล้วลากไฟล์ทั้ง 9 ไฟล์นี้ (ไม่ต้องสร้างโฟลเดอร์)ลงไป → **Commit changes**
3. ไปที่ **Settings → Pages → Branch: main / (root) → Save**
4. รอ 1–2 นาที เปิดลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
5. มือถือ: เมนูเบราว์เซอร์ → "ติดตั้งแอป" (iPhone: Safari → แชร์ → เพิ่มลงในหน้าจอโฮม)

## อัปเดตแอป
อัปโหลดไฟล์ใหม่ทับ แล้วเปลี่ยนเลขเวอร์ชันใน `sw.js` (บรรทัด `CACHE`) — ทั้งสองไฟล์ต้องเปลี่ยนเลขเวอร์ชันพร้อมกัน และ `app.js` (`APP_VERSION`) — ผู้ใช้จะเห็นแถบ "มีเวอร์ชันใหม่" ให้กดอัปเดต

ข้อมูลเก็บในเครื่อง (localStorage) — สำรองได้ที่ ⚙️ → ส่งออกไฟล์

## ฟังก์ชันหลัก (v3)
- เช็คลิสต์ก่อนออกบ้าน → ครบได้ดาวอัตโนมัติ
- ตารางเรียนเต็มรูปแบบ (เวลา + วิชา) และวันพิเศษ/วันหยุดโรงเรียน (กีฬาสี สอบ ทัศนศึกษา)
- ต้องส่งครู: การบ้าน เงิน เอกสาร พร้อมกำหนดส่งและยอดเงินรวม
- ภารกิจที่บ้าน + ดาวหลายแบบ (น้ำใจ ตั้งใจเรียน ช่วยงานบ้าน) แลกรางวัลได้
- เตือนเย็น/เช้า: เตือนเมื่อเปิดแอป และเพิ่มลงปฏิทินมือถือ (.ics) เพื่อเตือนแม้ปิดแอป
